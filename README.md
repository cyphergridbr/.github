# .github

Public profile of the CypherGrid organization on GitHub.

- `profile/README.md` - the page shown to everyone at the organization's
  GitHub page.
- `profile/README.pt-BR.md` - the same page in Brazilian Portuguese.
- `profile/assets/` - brand assets used by that page.
- `social-preview/` - 1280×640 images to set as the social preview of the
  organization's repositories (English and Portuguese).

This repository must stay **public** for the profile to be displayed.
Nothing in it may reference internal repositories, infrastructure, customers,
people's contact details or unmeasured numbers. Internal information belongs
in `.github-private`.

Changes go through a pull request reviewed by Paulo or Gustavo.
